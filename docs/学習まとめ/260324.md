### reduceについて
reduce関数は合計値を算出するときに使用する
- `sum`には現在の合計値が入る
- `value`には取り出した値が入る
- 最後の`0`は`sum`の初期値
- 以下の例で行くと,
    1. 1回目 sum(0) + value.amount(取り出した1つ目の金額)
    2. 1回目の合計結果 sum + value.amount(取り出した2つ目の金額)
```js
// 支出合計
const totalExpense = expenses.actualExpenses.reduce(
    (sum, value) => sum + value.amount, 0
)
```

### ディレクトリ移動コマンドの操作
zoxide（賢いcd）

よく行くディレクトリを学習して、途中の名前だけで飛べます。

cd frontend/src/components   # 普通のcd（これを繰り返すと学習される）

z components    # 学習後は「z + 部分名」だけで飛べる
z tabs          # frontend/src/tabs に飛ぶ
z savings       # savings_simulator に飛ぶ

インタラクティブ選択（fzfと連携）：
zi    # 候補一覧をfzfで絞り込んで選択

---
fzf（あいまい検索）

Ctrl+R — コマンド履歴をインタラクティブ検索
Ctrl+T — カレントディレクトリ以下のファイルをfzfで選択して入力
Alt+C — サブディレクトリをfzfで選択してcd

---
実際の操作イメージ

# このプロジェクトで使う場合
z savings      # → savings_simulator/ に移動
z frontend     # → savings_simulator/frontend/ に移動
z tabs         # → frontend/src/tabs/ に移動
zi             # → 候補リストから選んで移動
