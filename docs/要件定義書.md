# 要件定義書

## 概要
このアプリは、貯金額を管理し貯金のシミュレーションができるアプリです。
目的：計画的な資産形成を実現する

### 技術スタック
- Vite: "^5"
- React: "^18"
- Tailwind: "v4"
- node.js: "22.22.0"
- Typescript: "^5"

### 機能要件

#### 画面構成
3タブ構成（router-dom不使用・useStateで切り替え）

| タブ | 機能概要 |
|---|---|
| 収入 | 本業・副業手取りを入力・登録し、合計手取りと年収を表示 |
| 月次収支 | 月次の実績支出を入力・登録し、収支一覧と内訳グラフを表示 |
| 資産計画 | 現金貯金とNISAのシミュレーションを表示 |

---

### 画面一覧

#### 1. 収入タブ
- 本業・副業の手取り額を入力して登録（DB上は1件のみ・上書き更新）
- 合計手取り・年収をリアルタイム計算して表示

#### 2. 月次収支タブ
- 「支出入力ボタン」からモーダルを起動して実績支出を登録
- 収入合計・支出合計・月次余剰・黒字/赤字ステータスを表示
- 実績支出の内訳を円グラフで表示
- 登録済み月次データを一覧表示（年単位ページネーション・12件固定）

**支出入力モーダル:**
- 年月を選択して実績支出を項目ごとに入力
- 「項目管理」ボタンからモーダルonモーダルで支出項目と目標額を設定

**項目管理モーダル:**
- 支出項目の追加・削除
- 各項目の目標額を設定（DB上は1件のみ・上書き更新）

#### 3. 資産計画タブ
- 現金貯金月額・目標金額を入力し達成月数・達成年数を表示
- NISA積立月額・年利を入力し複利シミュレーショングラフを表示

---

### 計算ロジック仕様

#### 収入計算
```
合計手取り = 本業手取り + 副業手取り
年収      = 合計手取り × 12
```

#### 月次収支計算
```
支出合計   = Σ 実績支出[i].金額
月次余剰   = 収入合計 - 支出合計
ステータス = 月次余剰 >= 0 ? '黒字' : '赤字'
```

#### 資産計画：現金貯金
```
達成月数 = ceil(目標金額 / 現金貯金月額)
達成年数 = 達成月数 / 12
```

#### 資産計画：NISA複利
```
月利 = 年利 / 12

残高[0] = 0
残高[n] = (残高[n-1] + 積立月額) × (1 + 月利)

例: 月3万・年利5%・1年後 ≈ 370,000円
```
