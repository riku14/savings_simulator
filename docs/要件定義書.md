# 要件定義書

## 概要
このアプリは、貯金額を管理し貯金のシミュレーションができるアプリです。
目的：計画的な資産形成を実現する

### 技術スタック
- Vite: "^5"
- React: "^18"
- react-router-dom: "^6"
- Tailwind: "v4"
- node.js: "22.22.0"
- Typescript: "^5"

### 機能要件
- 画面一覧（どんな画面があるか）
- 各画面でできること（CRUD操作の明記）
- 計算ロジックの仕様（シミュレータなので最重要）
  → 例: 入力項目は何か、どう計算して何を出力するか

### 画面一覧
1. 収入計算
> - 「本業 + 副業」 の手取り額、合計額、年収を計算して表示する

2. 月次収支入力
> - 収入計算画面で登録している金額を収入としてデフォルト設定
> - 家賃、食費、日用品etc の支出を入力できる
> - 収入合計、支出合計、月次余剰を「収入 - 支出」で算出して表示

> - 上記は目標値として扱い、実際の収支を同様の項目で入力できる

3. 月次収支一覧
> - 月次収支入力画面で登録した内容を月次ごとに一覧として確認できる
> - 各月で目標が達成できているのかチェックしてステータスを表示する

4. 資産計画
> - 現金貯金 + NISA の貯金予定額をグラフとテキストで表示
> - 目標金額を入力することで達成までの期間を表示(現金貯金のみ)
>   → 月次収支入力画面で登録した情報から計算する
>   ```
>   達成月数 = 目標金額 / 月次余剰
>   達成年数 = 達成月数 / 12 
>   ```
> - NISAの金利は手入力
>     ```
>     1ヶ月目終了時: 30,000 × (1 + 0.05/12)
>     2ヶ月目終了時: (前月残高 + 30,000) × (1 + 0.05/12)
>     3ヶ月目終了時: (前月残高 + 30,000) × (1 + 0.05/12)
>     ...繰り返し
>
>     1年後の残高イメージ（月利 ≈ 0.4167%）:
>
>     ┌──────┬────────────┬────────────┐
>     │  月  │ 積立後残高 │ 利息後残高 │
>     ├──────┼────────────┼────────────┤
>     │ 1月  │ 30,000     │ 30,125     │
>     ├──────┼────────────┼────────────┤
>     │ 2月  │ 60,125     │ 60,375     │
>     ├──────┼────────────┼────────────┤
>     │ ...  │ ...        │ ...        │
>     ├──────┼────────────┼────────────┤
>     │ 12月 │ 369,750    │ 371,289    │
>     └──────┴────────────┴────────────┘
>     つまり 「先月の残高に今月分を足してから、月利をかける」 を12回繰り返したものが1年後の残高です。
>     ```

### 画面設計
1. 収入計算:number
   - 本業手取り
   - 副業手取り
   - 合計（本業＋副業）
2. 月次収支入力:number
   - 家賃
   - 食費・日用品
   - NISA積立
   - 保険・年金
   - 通信費
   - 娯楽
   - サブスク
   - その他
3. 月次収支一覧
   - 1と2の内容を一覧で表示
4. 資産計画
   - 目標金額
   - NISA積立額
   - NISA金利（デフォルト値オルカンを設定）
