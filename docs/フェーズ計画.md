## Phase 2：バックエンド

**目標:** Thunder ClientでCRUD操作が全て正常に返却される

### 完了基準
- [ ] `GET /api/income` — 収入データを返す
- [ ] `POST /api/income` — 収入を登録・上書き更新
- [ ] `GET /api/categories` — 支出項目一覧を返す
- [ ] `POST /api/categories` — 項目を一括保存（追加・更新・削除）
- [ ] `GET /api/monthly?year=2026` — 年単位で月次一覧を返す
- [ ] `POST /api/monthly` — 月次実績を登録
- [ ] Prismaクライアントがシングルトン（`backend/src/lib/prisma.ts`）

### タスク一覧

#### Prisma
- [ ] `schema.prisma` に4テーブル定義
  - `Income`, `ExpenseCategory`, `MonthlyRecord`, `ActualExpense`
- [ ] マイグレーション実行

#### Hono サーバー
- [ ] `backend/src/index.ts` — サーバー起動・ミドルウェア設定
- [ ] `backend/src/lib/prisma.ts` — Prismaシングルトン

#### APIルート（`backend/src/routes/`）
- [ ] `income.ts` — GET / POST（upsert）
- [ ] `categories.ts` — GET / POST（一括upsert・削除）
- [ ] `monthly.ts` — GET（年フィルタ）/ POST（月次登録）
